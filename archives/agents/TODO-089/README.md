# TODO-089 の分担

利用者向けの使い方（`docs/User.md`）を新しく書いた項目。

| 担当 | やったこと | 報告 |
|------|-----------|------|
| main | 実装を読んで事実を集め、下書きを書いた。スクリーンショットを撮り、`make_shots.py` を作った | — |
| wording | 下書きの推敲。用語と語の揃え | [wording-report.md](wording-report.md) |
| verifier | コマンド例・出力例・画面の記述・画像の再現確認 | [verifier-report.md](verifier-report.md) |

## この分担にした理由

- **下書きは main が書いた。** 画面の細部（諸元の項目、候補の表の列、
  ビューアの操作）は実装を読まないと書けない。その材料を集めるのが作業の
  大半で、集めた側がそのまま書くほうが受け渡しが要らない
- **推敲を wording に分けた。** 着手後に利用者が指示した。書いた本人は
  自分の語の揺れに気づけない（実際「上げる」と「アップロード」が混ざっていた）。
  定義のモデルは haiku だが、既存の文書との語の揃えを見る仕事なので
  Sonnet 5 に上書きした
- **再現の確認を verifier に分けた。** 「書いたとおりに試せるものがあるなら、
  その再現は必ず分ける」（`CLAUDE.md`、TODO-017）。コマンド例と出力例、
  画面のラベルを実装と突き合わせる仕事で、判断が要るので Sonnet 5 に上書きした
- **レビューの担当は入れていない。** 挙動も分岐も変えていない（文書と、
  画像を撮るだけのスクリプトの追加）
