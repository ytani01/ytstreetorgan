## 直した箇所

いずれも `docs/User.md`。事実（コマンド名・オプション・既定値・数値・画像パス）は
一字も変えていない。

1. **文が終わっていなかった箇所を直した（1〜8 行目）**
   「開発者向けの情報は `Developer.md` と `tech-stack.md`。」で切れていて、
   直前の「インストールと設定ファイルの置き方は README にある。」と対で
   読むと動詞が抜けていた。「にある。」を足した。

2. **同じ内容を述べる README の文と揃えた（47〜48 行目）**
   「テンプレートと、アップロードした…」の「と」を「や」に直した。
   README（`### Webインターフェース`）に同じ文（起動はリポジトリの
   ディレクトリで、という説明）があり、そちらは「テンプレートや、
   アップロードした…」と書いてある。同じ事実を述べる文なので語を揃えた。

3. **「アップロード」と「上げる」が混在していたのを統一した（78 行目、153 行目）**
   - 「同じ名前のファイルを前に上げていると」→
     「同じ名前のファイルを前にアップロードしていると」
   - 「上げた MIDI をその移調量で移調したもの」→
     「アップロードした MIDI をその移調量で移調したもの」

   `docs/User.md` 自身が見出し・画像キャプション・他の本文では
   一貫して「アップロード」を使っている（例: 「MIDIアップロード」の
   画面名、「アップロードした MIDI と、生成した SVG の一覧」）。
   リポジトリ内の他の文書（`CLAUDE.md` / `README.md` / `docs/tech-stack.md`）
   で「上げる」が使われているのは「バージョンを上げる」「タグを上げる」の
   意味だけで、ファイルの送信を指す用法は無かった。「同じものを別の言葉で
   呼ばない」の原則に沿って「アップロード」に揃えた。
