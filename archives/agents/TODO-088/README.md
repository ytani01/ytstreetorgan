# TODO-088 の分担

| 担当 | 受け持ち |
|------|----------|
| main | 突き合わせ、`TODO.md` / `CLAUDE.md` / `.claude/settings.json` の変更 |
| verifier | 変更後の確認（[report](verifier-report.md)） |

## この分担にした理由

文書と設定ファイルだけの項目なので、実装の担当は分けていない。

`verifier` を入れたのは、`CLAUDE.md` に足した「トークン消費量の集計」の節が
**書いたとおりに試せるコマンド例**を含むから（グローバル `CLAUDE.md` の
TODO-017 の決まり)。フックを消したあとに件数が出ることも、実際に走らせないと
分からない。

`reviewer` は入れていない。分岐や条件式が変わる項目ではないため。
