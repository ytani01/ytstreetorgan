## この分担にした理由

文書だけを変える項目なので、実装の担当は分けなかった。ただし確かめる中身が
「書式が揃っているか」だけではない（移した記述が欠けていないか、9 章ぶんの
説明が実装と合っているか）ので、`~/.claude/CLAUDE.md` が認めている
「main が確認してよい」例外には当たらない。確認は別の担当に分けた。

挙動は変わらず分岐も条件式も動かないので、レビューの担当は立てていない。

## 2 回に分けた理由

1 回目（Haiku 4.5）の指摘は 1 件だけで、それが誤りだった。
`RollBook` のプロパティ名（`note_count` ほか）を `storage.BookInfo` の
キー名（`notes` ほか）と取り違えて「実装と一致していない」と報告している。
そのうえ、main が自分で実装を読んで見つけた 3 件（穴の y 座標の上下が図と
逆、URL の表で prefix が混ざっている、依存の表からモジュールが 3 つ抜けて
いる）は拾えていない。

`~/.claude/CLAUDE.md` の「低いモデルが判断に迷った、失敗した、または重要な
根拠を示せないときは上位モデルへ切り替える」に当たるので、Sonnet 5 に
上書きしてやり直させた。2 回目は 1 件、新しい食い違いを見つけている
（1 章の図で、長い穴の分割が実線側だけにかかるように描いてあった。実装は
`HoleInfo` が `scale` を見ずに `segments` を求めるので破線も分割される）。
