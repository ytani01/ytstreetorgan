# TODO-082. 起動時の残件表示が、項目ではなくチェックボックスを数えている

## きっかけ

`.claude/settings.json` の SessionStart フックが `TODO.md` を awk で読んで
残件を表示している。`TODO.md` の項目見出しが `## TODO-NNN. 見出し` から
`### **TODO-NNN** 見出し` に変わったのに、フックが追随していなかった。

- 件数を `- [ ]` の数で数えていた（項目 4 件に対して 11 と出ていた）
- 打ち切り条件 `/^## 完了済み/` が今の `## == 完了済み` に一致せず、
  止まらない。項目名として節見出しを拾っていた

出ていたのはこれ。

```
TODO に残っているのは 11 件: == 着手前 / 検討中 / == 完了済み
```

## やったこと

awk を項目見出し基準にした。

```awk
/^## .*完了済み/{exit}
/^### /{n++}
END{if(n>0)printf "TODO に残っているのは %d 件", n}
```

- 数えるのは `### ` で始まる行（＝項目見出し）。チェックボックスは見ない。
  1 項目の中にいくつあってもよく、0 個でも数に入る
- 打ち切りは `/^## .*完了済み/`。見出しの飾り（`== `）が変わっても効くように、
  行頭一致ではなく途中一致にした
- **項目名は出さない。** 何件かぶん並べると 1 行が長くなるうえ、
  詳しくは `TODO.md` を読めば分かる

`[ -f "$f" ] || exit 0` と `jq -Rs 'select(length>0)'` は元のまま。

## テスト

`jq -r` でフックのコマンドを取り出して、そのまま `sh` で実行した。

- 実際の `TODO.md`（この項目を含む 5 件） → `TODO に残っているのは 5 件`。
  `grep -c '^### ' TODO.md` の 5 と一致
- 合成した `TODO.md`（残 2 件、うち 1 件はチェックボックス 2 個、
  「完了済み」節にも `### ` を 1 つ置いた） → `2 件`。
  チェックボックスの数にも、完了済みの `### ` にも引きずられない
- 「着手前」節が空 → 何も出さずに終了（`exit=0`）
- `TODO.md` が無い → 何も出さずに終了（`exit=0`）
