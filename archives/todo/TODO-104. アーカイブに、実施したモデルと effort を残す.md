# TODO-104. アーカイブに、実施したモデルと effort を残す

実施: Opus 5 / effort high（サブエージェントなし）

## きっかけ

項目を立てるときにモデルと effort を書く決まりは既にあったが、アーカイブへ
移す時点で消えていた。TODO-103 のファイルにも残っておらず、あとから
「この規模ならどれで足りたか」を振り返る材料が無かった。

立てたときに書くのは**見込み**で、実際に使ったモデルとは食い違うことが
ある。振り返りに要るのは実際のほうなので、決着した時点で書き直す形にした。

（この項目自体、立てるときは Sonnet / low と見込んだが、実際には Opus 5 /
high で実施した。上の 1 行はそちらを書いてある。）

## やったこと

`~/.claude/CLAUDE.md` のアーカイブの骨格の記述に、見出しの直後へ 1 行
足す決まりを書いた。

```markdown
# TODO-103. 見出し

実施: Opus 5 / effort high（サブエージェントなし）
```

サブエージェントを編成したときは `実施: サブエージェント（archives/agents/TODO-103/）`
と参照だけ書く。誰にどのモデルと effort を充てたかを
`archives/agents/TODO-NNN/README.md` に書く決まりは既にあるので、二重に
持たせない。

書式は既存の骨格（きっかけ / やったこと / テスト）を崩さないよう、節を
増やさず見出しの直後の 1 行にした。

**既存の 103 件には遡らない。** 実施したモデルの記録が残っておらず、
書けないため。

ではない（TODO-057 と同じ扱い）。
