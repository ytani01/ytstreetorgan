# TODO-089. 起動時の残件表示が、今の項目見出しに合っていない

作成: 2026-08-19
決着: 2026-08-19

## きっかけ

`.claude/settings.json` の SessionStart フックが、残件があっても
何も出さなくなっていた。

TODO-082 で直したときの項目見出しは `### **TODO-NNN** 見出し` で、awk は
`/^### /` を数える形にした。その後 6656a03（2026-08-12）以降は
`## TODO-NNN. 見出し`（`~/.claude/CLAUDE.md` の骨格に合わせた形）に
戻っており、`### ` で始まる行が無い。`n` が 0 のままなので
`END{if(n>0)...}` に入らず、無言で終わっていた。

## やったこと

数える行を項目見出しに合わせた（awk の 1 か所だけ）。

```awk
/^## .*完了済み/{exit} /^## TODO-/{n++} END{if(n>0)printf "TODO に残っているのは %d 件", n}
```

- `/^### /` → `/^## TODO-`。**見出しの飾りではなく `TODO-` で見分ける**ので、
  同じ `## ` で始まる `## == 着手前 / 検討中` を数に入れない
- 打ち切り条件 `/^## .*完了済み/` は今の `## == 完了済み` に一致するので
  そのまま。完了済みの節にある目次は `- [**TODO-NNN.**` という一覧の行で、
  行頭が `## ` ではないため、打ち切りが効かなくても数には入らない
- `[ -f "$f" ] || exit 0` と `jq -Rs 'select(length>0)'` は元のまま

## テスト

`jq -r` でフックのコマンドを取り出し、`CLAUDE_PROJECT_DIR` を差し替えて
そのまま `sh` で実行した。

- 実際の `TODO.md`（この項目を含む 1 件） → `TODO に残っているのは 1 件`
- 合成した `TODO.md`（残 2 件、うち 1 件はチェックボックス 2 個、
  「完了済み」節にも `## TODO-` を 1 つ置いた） → `2 件`。
  チェックボックスの数にも、完了済みの見出しにも引きずられない
- 「着手前」節が空 → 何も出さずに終了（`exit=0`）
- `TODO.md` が無い → 何も出さずに終了（`exit=0`）
