# TODO-066. アーカイブのファイル名が壊れている件を直す

作成: 2026-08-12
決着: 2026-08-12

## きっかけ

`archives/todo/` に壊れたファイル名が 2 件残っていた。

- **TODO-061** — `git mv` の際にタイトルをそのまま渡したところ、シェルが
  URL エンコードした文字列がファイル名になってしまい
  （`TODO-061.%20%E5%AE%9A%E5%9E%8B…`）、`TODO.md` の目次からリンク切れに
  なっていた。同じ番号で中身の無い 0 バイトの未追跡ファイル
  （デコードした日本語名）も残っていて、2 つ TODO-061 が存在する
  紛らわしい状態だった
- **TODO-060** — タイトルに `docs/multi_agent_token_savings.md` という
  スラッシュ入りの参照を含めたため、`git mv` が
  `archives/todo/TODO-060. ドキュメント docs/` という**ディレクトリ**を
  作ってしまい、その下に本文ファイルが置かれていた（TODO-062 のアーカイブに
  同じ罠への言及がある）

## やったこと

- TODO-061 の 0 バイト・未追跡ファイルを削除した
- TODO-061 の実ファイルを `git mv` で
  `TODO-061. 定型検証サブエージェント委任ドキュメントの作成.md` に
  リネームした。デコードすると元のタイトルは「サベ」「営任」という
  誤字を含んでいたため、正しい「サブ」「委任」に直した
  （本文の見出しと `TODO.md` の目次の表示テキストは元々正しく、
  ファイル名だけがずれていた）
- TODO-060 の本文ファイルを、ディレクトリの外の 1 ファイルに `git mv` した。
  タイトルの `docs/multi_agent_token_savings.md` は全角スラッシュ
  （`／`）に置き換えて `TODO-060. ドキュメント docs／multi_agent_token_savings.md へレビューに基づく補足・提案の組み込み.md`
  とし、空になったディレクトリを削除した
- `TODO.md` の目次の 2 件のリンクを、それぞれ新しいファイル名に合わせた

## 再発を防ぐ決まり

- **タイトルにスラッシュを入れない。** `docs/foo.md` のような参照は
  ファイル名ではなく本文に書く。避けられない場合は中黒（`・`、TODO-062）や
  全角スラッシュ（`／`、TODO-060）に置き換える
- **`git mv` にタイトルをそのまま渡さない。** シェルの展開や URL
  エンコードが紛れ込んでいないか、`git mv` の直後に
  `git status` でファイル名を確かめる

  正しい行き先を指していることを確認した
- `test -f` で新しいファイル名が実在することを確認した
- コードは変更していないので `pytest` / `ruff` / `mypy` の対象になる
  変更は無い
