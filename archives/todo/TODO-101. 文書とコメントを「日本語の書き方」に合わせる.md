# TODO-101. 文書とコメントを「日本語の書き方」に合わせる

## きっかけ

ユーザー全体の `CLAUDE.md` に「日本語の書き方」の節を足した（2026-08-19）。

- 自然な日本語で書く。英語からの直訳になっていないか見直す。
  日本語では要らない主語（「私は」「あなたが」）を付けない
- 専門用語・エラーコード・例外名は無理に和訳しない
- 一般的な IT 用語は、普通のカタカナ表記か英語のまま書く

この決めごとに合っていないところが、このリポジトリにも残っていないかを見た。
`archives/` は決着した記録なので対象外にした。

## やったこと

洗い出しは `survey` に投げた。`docs/`・各 `CLAUDE.md`・`README.md`・
`DOCTOR.md`・JS / HTML のコメントは**該当なし**で、直したのは 15 行だけ。

`src/ytstreetorgan/rollbook.py` の docstring 1 行目（7 か所）。
「〜のインスタンスを初期化する」「オブジェクトの文字列表現を取得する」の
ような、英語の docstring をそのまま訳した形になっていた。同じファイルの
プロパティの docstring は「何のためか」を書く文になっていて、そちらに揃えた。

| 前 | 後 |
|---|---|
| MIDI ノート番号からトラック番号（インデックス）を取得する。 | MIDI ノート番号に対応するトラック番号を返す。 |
| 矩形描画用のSVGパス文字列を生成する。 | 矩形を描く SVG のパス文字列を返す。 |
| HoleInfoのインスタンスを初期化する。 | 音符 1 つぶんの穴の位置と長さを求める。 |
| オブジェクトの文字列表現を取得する。 | デバッグ用に、穴の諸元を 1 行にまとめる。 |
| 穴描画用のSVGパス文字列を生成する。 | 穴を描く SVG のパス文字列を返す。 |
| RollBookインスタンスを初期化する。 | 機種の設定を読み、移調量を決めておく。 |
| ロールブック全体を描画するSVGドキュメント文字列を生成する。 | ブック全体の SVG を組み立てて返す。 |

同じファイルの `Returns:`（5 か所）。「生成されたSVGパス要素の文字列。」→
「SVG のパス要素の文字列。」、「生成されたSVG形式のテキスト文字列。」→
「SVG のテキスト。」。

画面の文言（`webroot/templates/storgan.html`）。「…音源に近いメロディーを
再現できるよう最適化することができます。」は「できる」が二重で冗長だった。
「…キーを変えて、なるべく音源に近いメロディーになるよう最適化します。」に
短くした。**コメントではないが、対象に含めることにした**（利用者が読む文
なので、ここが冗長なままでは意味が無い）。3 行だったのが 2 行に収まった。

`tests/test_conf.py` の「`FileNotFoundError` が送出される」→
「`FileNotFoundError` になる」。**例外名は残した。** 他所は「例外になる」で
揃っているが、ぼかすより具体的な名前があるほうが分かりやすい。

触らなかったもの:

- `Args:` の `(str, optional)` 形式、「デフォルトは X」の繰り返し。
  言い回しの問題ではない（`rollbook.py` だけこの書き方という揺れはあるが、
  今回の対象ではない）
- 文体（である調 / ですます調）の統一
- `CLAUDE.md`「画面に出す用語」で決めた語（トラック / 音名 / 音階 /
  移調 / 調 / 音の長さ / 試聴 / ダウンロード）
