# TODO-036. ビューアの倍率の上限を 10 倍にする

`viewer.js` の `Z_MAX` を 5.0 から 10.0 にした。

原寸（1.0）の 5 倍では、穴の縁や短い穴の並びを確かめたいときに足りない。

決めたこと:

- **下限（`Z_MIN` = 0.02）は変えない。** 「全体」がそこに収まっている
- スライダの目盛（0〜100）も変えない。刻みが対数なので、上限が伸びた分だけ
  同じつまみの位置がやや高い倍率を指すようになるだけ
- 既定の表示は「高さ合わせ」のまま。上限の変更に影響されない

## 入れたもの

定数 1 つ（`webroot/static/js/viewer.js`）。

```js
const Z_MIN = 0.02;
const Z_MAX = 10.0;
```

対数の刻みを説明するコメントの「500%」も 1000% に直した。テンプレート側に
上限は書かれていない（スライダは 0〜100 の目盛で、倍率への変換は
`fromSlider()` が持っている）。

## 確かめたこと

- 原寸から `＋` を 8 回押すと 1000% で止まる
  （`tests/browser/test_rollbook_page.py::test_viewer_zoom_controls` に追加）
- `Z_MAX` を 5.0 に戻すとこのテストが落ちる（実際に戻して確認）
- `uv run pytest -q` / `uv run pytest -m browser -q` とも通る
