# TODO-053. 「調」「移調」を素人にも分かるように画面で説明する

## きっかけ

「移調ってキーを変えることだよね？」と訊かれた。だいたいそうだが、
このリポジトリでは**移調（半音数の合計）と調（キーが動くぶん）を
分けて**使っている（`CLAUDE.md` の用語表）。+12 は移調しているが
キーは変わらない、という関係が画面からは読み取れなかった。

画面には「調」「オクターブ」「移調」の 3 列が並んでいるのに、
どれがどう違うかの説明が無く、音楽をやらない利用者には区別が付かない。

## やったこと

- `webroot/templates/_terms.html` — 用語の説明。`<details>` にして
  畳んでおく（毎回読むものではない）
- `storgan.html` の 2 か所で `{% include %}` する
  - アップロードの「キー（移調）」の下
  - 生成結果の「キー（移調）を変えて作り直す」の中
- `my.css` に `.terms` の見た目

説明する語は 4 つだけにした。**移調・半音・オクターブ・調。**
表の列（調 / オクターブ / 移調）を読むのに要るのはこれで足りる。

## やらなかったこと

**用語ごとのツールチップにはしない。** 3 つの語の関係
（移調 = 調 + オクターブ）が要点なので、ばらばらに出すと伝わらない。

**常時表示にもしない。** 一度読めば済む説明で、二度目からは
候補の表を隠すだけになる。

## テスト

`tests/test_rollbook_page_http.py` に 2 件。アップロードの画面と
生成結果の画面の両方に説明が出ること。
