# TODO-021. base テンプレートを切る

旧番号: **M**（コミットメッセージはこの記号で書いてある）

`webroot/templates/base.html` を作り、3 本のページをそこから継承させた。
`<head>`・appbar・フッター・live reload の 1 行が 1 か所になった。

各ページが持つのは差分だけ。

| ブロック | 中身 |
|---|---|
| `head` | ページごとの `<script>`（`MODELS_DATA` など） |
| `content` | `<main>` の中身 |
| `dialogs` | `<main>` の外に置くモーダル（同名確認・機種追加） |
| `scripts` | ページごとの `<script src=…>` |

- ナビの現在地は各ハンドラが `nav='top' / 'history' / 'config'` を渡す。
  テンプレート側で判定すると、結局ページごとに書くことになるため
- `window.URL_PREFIX` は全ページで要るので `base.html` に置いた

Tornado の継承は `{% extends %}` + `{% block %}`。子テンプレートの
ブロック外に書いたものは出力されない（実際に確かめた）。

テスト 4 本追加（178 → 182）。ナビが全ページに出ること、現在地の印が
1 か所だけで正しいリンクに付くこと、CSS と `URL_PREFIX` が全ページに
あること。live reload のテストも履歴を含めた全ページを見るようにした。

**注意**: テンプレートは行頭の空白を落とすので、生成された HTML を
文字列で突き合わせるテストはインデントに依存させないこと（一度これで
落とした）。
