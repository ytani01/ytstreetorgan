# TODO-026. 図から求まらない値を SVG に埋める

旧番号: **T-2**（コミットメッセージはこの記号で書いてある）

`RollBook._meta_attrs()` が `<svg>` に属性として埋め、
`storage.book_from_svg()` が読む。これで履歴の「表示」でも諸元が全部出る。

    <svg … viewBox="…"
         data-storgan-model="34notes"
         data-storgan-mm-per-sec="50"
         data-storgan-notes="1033"
         data-storgan-hole-notes="562"
         data-storgan-off-scale-notes="471">

埋めるのは**図からは求まらないものだけ**。寸法は `width` / `height` 属性、
穴と破線の数は描かれているものを数えれば分かるので、二重に持たない
（持つと手で編集したときに食い違う）。

| 表示 | 埋める前 | 埋めたあと |
|---|---|---|
| 演奏時間 | `---` | `1:22` |
| 音符 | `---` | `1033` |
| 穴 | `--- → 566 個` | `562 → 566 個` |
| 破線 | `--- → 471 個` | `471 → 471 個` |
| 1 秒 | `---` | `50 mm` |

**属性が無い SVG（埋める前に作ったもの）は `---` のまま**。実際に手元の
古い SVG で確かめた。壊れた値（`data-storgan-notes="abc"`）も `---` に落とす。

名前を `data-storgan-` で始めているのは、他のツールが付けた属性と
紛れないようにするため。`model` は今のところ表示していないが、
どの機種で作ったかは SVG からは分からないので入れてある。

生成 → 読み直しで**全項目が一致する**往復テストがある。色や属性名を
変えると落ちる。
