# K. 履歴の画面

`/storgan2/history` を足した。`webroot/midi/` と `webroot/svg/` の中身が
画面から見えるようになり、消すのにファイルマネージャを開かなくてよくなった。

- 2 カラム（MIDI / SVG）。名前・サイズ・更新日時を新しい順に
- 個別削除と全部削除（どちらも `confirm()` で確認してから）
- ダウンロード。MIDI 用に `/download/midi/<name>` を足した
  （SVG は生成結果の画面のリンクが元からこの形なので `/download/<name>` のまま）
- MIDI を選んで再生成（画面で選んでいる機種で作り直す）
- SVG を選んで再表示（生成し直さずそのまま出す）

**再表示の諸元は SVG から読めるぶんだけ。** `width` / `height` は
`<svg width="…mm" height="…mm">` にあるので読む。穴の数と `mm_per_sec` は
無いので `---` と出す（演奏時間と現在位置の秒表示も `---`）。
「生成しました」ではなく「履歴から表示」と出し、添えるサイズも
元 MIDI ではなく SVG 自身のものにした。

**ファイル名を外から受け取る経路ができた。** `storage.py` に集めてある。
`safe_name()` が区切り文字と `..` を弾き、`resolve_in()` が解決後も置き場の
中にあることを確かめる（シンボリックリンクで外へ出る場合も弾く）。
削除・ダウンロード・再生成・再表示のすべてがこれを通る。

`Handler1.post()` は `stored_midi` / `stored_svg` を見て分岐する。
生成結果の画面を出すのは 1 か所（`_render()`）のままにしたかったため。
