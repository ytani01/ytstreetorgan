# TODO-034. 紙の色を古紙っぽくする

ビューアの紙の色を、白から古紙っぽい茶（`#e8d8b8`）に変えた。

**紙の色は SVG に入っていない。** 生成される SVG には背景の矩形も
`background` も無く、白は `my.css` の `.svgbox > svg { background: #fff }`
だけで決まっている。**変えても生成物には影響しない**（TODO-033 と同じ
原理だが、こちらはインラインの style 属性と競合しないので `!important`
すら要らない）。

決めたこと:

- 色。候補を 3 段階で見比べた
  - `#f0e4cc` … 古紙感は出るが、まだ白寄り
  - **`#e8d8b8`** … 古紙らしく、赤の穴も黒の破線もはっきり読める ← これにした
  - `#ddc9a3` … 一番らしいが、赤の塗りが紙に馴染みすぎる
- **暗い紙にはしない。** 破線（音階に無い音）は `#000000` なので暗い紙だと
  消える。あれは「どの音が鳴らないか」を目視するためのものなので、
  消しては意味が無い（実際に撮って確かめた）

## 入れたもの

トークンを 1 つ足し、参照させただけ（`webroot/static/css/my.css`）。

```css
:root {
  /* 明暗テーマで切り替えない。破線が #000000 なので暗い紙だと消える */
  --paper: #e8d8b8;
}

.svgbox > svg { background: var(--paper); … }
```

`!important` は要らない。穴の線と違って、インラインの style 属性と
競合していないため（紙の色は SVG に入っていない）。

## 確かめたこと

- 明暗どちらのテーマでも `rgb(232, 216, 184)` になる（切り替わらない）
- 保存される SVG は無変更（TODO-033 のテストが引き続き見ている）
