# TODO-035. 穴を「くり抜いた」ように見せる

実線の穴を黒で塗り潰し、縁はカットラインの赤を残した。
音階に無い音（破線）は、黒から暖かみのあるグレーにして色を薄くした。

画面の色は SVG と無関係に決められる（TODO-033・TODO-034）。だったら
**穴は実際にくり抜いたように黒くしたほうが、この道具の実態に近い。**

決めたこと:

- **縁の赤は残す。** 黒く塗るだけだと、音階に無い音（`#000000` の破線）と
  色で区別が付かなくなる。「どの音が鳴らないか」を目視するのは README にも
  書いてある主要な用途なので、そこは落とせない
- **鳴らない音はグレーにして色を薄くする。** 穴（黒く抜けている）との差を、
  色の濃さでも付ける。紙が茶なので、暖かみのあるグレーで揃える
- 塗りが不透明になるので、`fill` の値を紙より暗くすること

## 入れたもの

トークンを 2 つ足し、CSS を 2 本足しただけ（`webroot/static/css/my.css`）。

```css
:root {
  --punch:     #1c1a17;   /* 開けた穴の中身 */
  --off-scale: #8a7c66;   /* 音階に無い音 */
}

/* 実線の穴。縁の赤（カットライン）は残す */
.svgbox > svg path[style*="stroke:#FF0000"] { fill: var(--punch) !important; }
/* 音階に無い音。消さずに色を薄くする */
.svgbox > svg path[style*="stroke:#000000"] { stroke: var(--off-scale) !important; }
```

比べた案:

| | 見た目 | 鳴らない音との区別 |
|---|---|---|
| 黒で塗り潰し | ◎ くり抜きそのもの | △ 塗りの有無だけ |
| **黒塗り + 赤い縁** | ○ くり抜き + カットラインが見える | ◎ 縁の赤で一目 ← これ |
| 焦茶で塗り潰し | ○ 紙に穴＝影、という感じ | △ 同上 |
| 赤 35% 塗り（前） | △ 図面っぽい | ◎ |

## 確かめたこと

- 実線: `fill` が `rgb(28, 26, 23)`、`stroke` は `rgb(255, 0, 0)` のまま
- 破線: `fill` は `none`、`stroke` は `rgb(138, 124, 102)`
- どれかの CSS を外すとテストが落ちる（実際に外して確認）
- 保存される SVG は無変更（TODO-033 から続けて見ている）
