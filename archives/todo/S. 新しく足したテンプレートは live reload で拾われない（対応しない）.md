# S. 新しく足したテンプレートは live reload で拾われない（対応しない）

`tornado.autoreload.watch()` は起動時にあるファイルしか見ないので、
テンプレートや静的ファイルを**新規に足したとき**は手で再起動が要る。
既存ファイルを直したぶんは今までどおり自動で反映される。

開発時だけの話で、ファイルを足すのは稀なので**このままとする**。
（CLAUDE.md の live reload の節に、この制約は書いてある。）
