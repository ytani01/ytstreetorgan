# TODO-033. ビューアで穴が見にくい

画面で見るときだけ、線を 1px にして実線の穴に薄い塗りを入れた。

**原因は白地ではなく、線が 1px 未満なこと。** 生成する SVG は
`stroke-width:0.2` に `vector-effect:non-scaling-stroke` を付けている。
これは**変形を無視して指定値をそのまま画面の単位で描く**ので、倍率に
関わらず 0.2px になり、アンチエイリアスで薄いピンクに潰れる。
背景を暗くしても改善しない（コントラストの向きの問題ではない）。

**SVG は変えない。** 線の色はレーザー加工機の仕様で決まっていて、
太さも変えたくない。ビューアは SVG をページに埋め込んでいるだけなので、
**CSS で上書きすれば画面だけ変わる**。ダウンロードは `webroot/svg/` の
ファイルをそのまま返すので、渡すファイルは無変更のまま。

決めたこと:

- 線は 1px。`style="…"` 属性で書かれているので `!important` が要る
- **実線（開ける穴）にだけ薄い赤の塗り**を入れる。塗りはパスの内側なので
  **穴の見かけの大きさが変わらない**（線を太くするだけだと、輪郭が内外に
  太って穴が少し大きく見える）
- 破線（音階に無い音）は塗らない。これで**実線＝塗りあり / 破線＝線だけ**と
  意味の違いも一目で分かる
- 低倍率では輪郭だけの矩形は消えるが、塗りは残る

実測: CSS を外すと、画面での計算値は `0.2px` に戻る（テストがそれを見て
いる）。ダウンロードされる SVG に `stroke-width:0.2` と `fill:none` が
残っていることも同じテストで確かめている。
