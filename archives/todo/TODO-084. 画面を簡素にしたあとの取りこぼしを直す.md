# TODO-084. 画面を簡素にしたあとの取りこぼしを直す

## きっかけ

811372d「画面構成をシンプルにした。」のあと、文言と実態が食い違う所と、
中身だけ消えて残った空要素があった。テストは通常 297 / ブラウザ 49 とも
通っていたので、テストでは気付けなかった。

## やったこと

### ロールブックの画面（`webroot/templates/storgan.html`）

1. 試聴プレーヤーの下の文言「下の表で移調を選ぶと、ロールブックと
   一緒に切り替わります。」を、`show_transpose_table` が true のときだけ
   出すようにした。表が無いとき（移調しても改善しないとき）は出さない。
   プレーヤー自体が `<section class="panel">` の外に出て常に表示される
   ようになったこと自体は改善なので、それは戻さず、文言だけを条件で
   分けた
2. `{% if %}` / `{% else %}` / `{% end %}` の間の改行が HTML の空白として
   残り、「移調しない場合␣の音を」のように余分な空白が入っていたのを、
   タグの直後にテキストを続けて改行を挟まない形にした

### 機種設定の画面（`webroot/templates/config_editor.html`）

3. 中身だけ空になっていた `<p class="page-lead">` をタグごと削除した
4. 中身が空の `<thead>` を削除した（見出しは戻さない）
5. 表の下に残っていた空の `<div class="panel__body" style="border-top:…">`
   をタグごと削除した

### CSS（`webroot/static/css/my.css`）

6. 未使用になっていた `.savebar` / `.savebar__msg` / `.savebar button` を
   削除した（`webroot/` 配下に参照が無いことを grep で確認済み）
7. 「左カラム（基本寸法＋ブリッジ）」というコメントを、ブリッジの節が
   独立していない今の実態（「左カラム（基本寸法）」）に合わせた
