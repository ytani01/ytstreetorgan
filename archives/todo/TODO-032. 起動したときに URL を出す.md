# TODO-032. 起動したときに URL を出す

旧番号: **X**（コミットメッセージはこの記号で書いてある）

`webapp` を起動すると、開く URL を 1 行で出す。**Shift + クリック
（端末によっては Ctrl / ⌘ + クリック）でブラウザが開く。**

```
  http://localhost:10081/storgan2/
```

- **`print()` で stdout に出す**（loguru ではない）。ログの水準に
  関わらず必ず出したいのと、loguru は stderr へ `file:line` 付きで
  出すので**URL だけの行にならない**（端末がリンクとして拾いにくい）
- 前後を空行で挟み、URL だけの行にする
- ホストは `localhost` 固定。listen は 0.0.0.0 なので LAN の別端末からも
  開けるが、**そこまでは案内しない**（普通は手元で使うため）
- 末尾のスラッシュは付ける。無いと `Handler1.get()` がリダイレクトする
- `-p` と `-u` を変えたときも、そのとおりの URL が出る（実機で確認）
