# TODO-054. 移調の候補から「調」「オクターブ」の列を削除する

## きっかけ

候補の表に「調」「オクターブ」「移調」の 3 列が並んでいた。
実際に効くのは合計の半音数（移調）だけで、素人には 3 つの関係が
分からない。TODO-053 で用語説明を足したが、**説明が要るのは
「画面に出しているから」**で、出さなければ説明も要らない。

## やったこと

- `storgan.html` — 「調」「オクターブ」の列を削除。作り直すボタン
  （`button[data-transpose]`）は「移調」の列に移した。
  ボタンの文言は `±0` ではなく **「移調しない」**（移調量が 0 のときだけ
  そう書ける。CLAUDE.md「画面に出す用語」）
- `_terms.html` — 「調」「オクターブ」の説明を削除し、「移調」と単位の
  「半音」だけにした。見出しも「「移調」とは？」
- 表の上の説明文から「調 が ±0 の行はキーが変わりません」を削除
  （その列がもう無い）
- `transpose.py` の `transpose_notices()` — 文面を**移調量**で書き直した。
  「音符の数では 調+3」と言われても、表に調の列が無いのでどの行か
  分からない。「キーを変えない」案の知らせも移調量で示す
- MIDI ダウンロードの `title` の「この調に移調した」→「この移調量で」

## やらなかったこと

**`key` / `octave` のデータは残す。** 候補の絞り込み（同じ調の中から
1 つ選ぶ）と並べ替え（`transpose_rank_key()`）、CLI の一覧表示が使う。
画面に出さないだけ。

  **本文全体に「オクターブ」が無いことでは見ない**（テンプレートの
  HTML コメントに語が残るため）
- `tests/browser/test_rollbook_page.py` は `button[data-transpose]` で
  押しているので、列が移っても通る（意図どおり）
