# TODO-055. 移調まわりの画面を整理する（メニュー削除・説明の短縮・列揃え）

## きっかけ

TODO-054 の続き。画面を見て 3 点。

1. トップ画面の「キー（移調）」のメニューが要らない
2. 用語説明の見出し「（音楽が分からなくても大丈夫です）」が**失礼**。
   説明本文も長すぎる
3. 候補一覧の列が揃って見えない

## やったこと

- `storgan.html`（トップ）— 移調の `<select>` を削除。**選ぶ場所は生成後の
  候補の表だけ**にした。2 か所あっても迷うだけで、候補は生成しないと
  出せない。サーバーは `get_argument('transpose', '0')` なので、
  値が来なくてもそのまま（移調しない）で動く。
  「生成すると候補の一覧が出る」という案内は残した
- `_terms.html` — 見出しは「「移調」とは？」だけ。**読み手の知識を
  値踏みする書き方をしない。** 本文も移調そのものの一段落だけに縮めた
  （半音の単位、この道具で移調する理由は削除）
- 列揃え — 見出しの `<th>` に中身と同じ寄せ方の class を付け
  （`.num` = 右、`.act` = 右）、`my.css` で右寄せにした。
  `table.hist thead th` が左寄せなので、**中身だけ右に寄っていて
  見出しが左端に残っていた**のが「揃っていない」の正体。
  あわせて `#transpose-table { width: auto; }`。画面幅いっぱいに
  引き伸ばすと列の間が間延びして、行を目で追えない

## 注意

見出しに `.hist__act` を付けてはいけない（`font-size: 0` で「MIDI」の字が
消える）。右寄せ用に `.act` を別に用意してある。
