# TODO-057. TODO 運用の食い違いをグローバルの決まりに寄せる

## きっかけ

`~/.claude/CLAUDE.md`（全プロジェクト共通）の「TODO.md でのタスク管理」と、
このリポジトリの実態（`TODO.md`、`archives/todo/` の 56 件、
`.claude/settings.json` のフック、メモリ `todo-md-workflow.md`）を
突き合わせたら 4 点ずれていた。

1. **コミットハッシュを添える** — メモリにだけある決まり。グローバルには
   無く、56 件中ハッシュがあるのは 4 件で、しかもその大半は上流や別の
   コミットへの参照。TODO-049〜056 は 0 件
2. **コミットを 2 回に分ける** — `docs(todo): …として立てる` は
   TODO-037（`34d7a30`）が最後で、以降 19 件は完了時の 1 本だけ
3. **完了コミットの書式** — `（TODO-048 完了）` のように「完了」が付く、
   TODO-047 なのに番号が無い、3 件まとめて `（TODO-054 / 055 / 056）` など
4. **`## 着手順`** — SessionStart フックがこの見出しを読み飛ばす作りに
   なっていたが、グローバルにもこのリポジトリのどの文書にも無く、
   `TODO.md` にも無い。過去の名残

**今後はグローバルに寄せる。過去のものは直さない**（2026-08-07 に決めた）。

## やったこと

- メモリ `todo-md-workflow.md` から「完了へ移すときはコミットハッシュを
  添える」を削除した（グローバルに無い決まりなので）
- `.claude/settings.json` の SessionStart フックから
  `/^## 着手順/{next}` を削除した
- `CLAUDE.md`「注意」から `archives/` の記述を削除した。グローバルの
  「`archives/` は**現行仕様ではない**。実装の根拠として参照しない」と
  重複していたため（重複はプロジェクト側を削除すると決めた）

2 と 3 は今後の書き方の話なので、ファイルの変更は無い。この項目自体を
グローバルどおり `docs(todo): …として立てる` → `docs: …（TODO-057）` の
2 コミットに分けて進めた。
