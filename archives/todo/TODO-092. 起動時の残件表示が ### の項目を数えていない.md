# TODO-092. 起動時の残件表示が `###` の項目を数えていない

作成: 2026-08-19
決着: 2026-08-19

## きっかけ

TODO-089 で awk のパターンを `/^### /` から `/^## TODO-/` に変えたが、
`TODO.md` の項目は `## == 着手前 / 検討中` の下にぶら下がる `### TODO-091.`
のように 3 個の `#` で書かれている。`/^## TODO-/` は 3 文字目が `#` なので
当たらず、未完 1 件だった `d1caa05` の `TODO.md` にコマンドをそのまま
当てても何も出ずに終わる（TODO-089 で直したはずの状態に戻っていた）。

## やったこと

`#` の個数に依らず拾えるように、awk のパターンを直した（1 か所だけ）。

```awk
/^## .*完了済み/{exit} /^#+ +TODO-/{n++} END{if(n>0)printf "TODO に残っているのは %d 件", n}
```

- `/^## TODO-/` → `/^#+ +TODO-/`。`##` でも `###` でも `TODO-` で始まる
  見出しなら拾う
- `## == 着手前 / 検討中` は `TODO-` を含まないので相変わらず当たらない
- 打ち切り条件 `/^## .*完了済み/` はそのまま

## テスト

`.claude/settings.json` から抜いた awk 部分を、実際の `TODO.md`（未完了
3 件）と、完了済みのみのダミー `TODO.md`（未完了 0 件）に対して実行して
確かめた。

- 未完了 3 件の `TODO.md` → `TODO に残っているのは 3 件`
- 完了済みのみのダミー → 何も出さずに終わる
